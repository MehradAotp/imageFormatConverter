# مبدل تصویر پرو

یک اکستنشن حرفه‌ای و حریم‌خصوصی‌محور برای Chrome که توسط **MrAOTP** طراحی و توسعه داده شده است.

## امکانات

- تبدیل تصویر با کلیک راست به PNG، JPG، WebP، AVIF، BMP و TIFF
- encoder واقعی برای BMP و TIFF؛ فرمت انتخاب‌شده دیگر به‌صورت مخفیانه به PNG تبدیل نمی‌شود
- پشتیبانی از AVIF در مرورگرهایی که encoder آن را ارائه می‌کنند
- داشبورد حرفه‌ای برای اسکن تصاویر صفحه، پیش‌نمایش، جست‌وجو، انتخاب گروهی و خروجی گرفتن
- تغییر اندازه با حفظ نسبت تصویر
- تنظیم کیفیت WebP، JPG و AVIF
- انتخاب رنگ پس‌زمینه برای تصاویر شفاف هنگام تبدیل به JPG
- انتخاب نام فایل اصلی یا نام‌گذاری بر اساس زمان تبدیل
- پردازش کاملاً محلی؛ تصاویر از مرورگر خارج نمی‌شوند
- رابط کاربری کاملاً فارسی، راست‌به‌چپ و با فونت Vazirmatn

## نصب محلی

1. به `chrome://extensions` بروید.
2. گزینه‌ی **Developer mode** را فعال کنید.
3. روی **Load unpacked** کلیک کنید.
4. پوشه‌ی پروژه را انتخاب کنید.

## روش استفاده

روی یک تصویر کلیک راست کنید و از مسیر **مبدل تصویر پرو · MrAOTP** فرمت خروجی را انتخاب کنید. برای پردازش چند تصویر، روی صفحه کلیک راست کرده و **باز کردن داشبورد تصاویر صفحه** را بزنید یا از popup گزینه‌ی **اسکن تصاویر این صفحه** را انتخاب کنید.

برای تنظیمات کیفیت، ابعاد، نام فایل و رنگ JPG، صفحه‌ی تنظیمات اکستنشن را باز کنید.

## محدودیت‌ها

پشتیبانی AVIF به encoder داخلی مرورگر وابسته است. BMP و TIFF توسط encoder داخلی اکستنشن ساخته می‌شوند. محدودیت‌های CORS، نیاز به ورود، منابع محافظت‌شده و صفحات داخلی Chrome ممکن است دسترسی به بعضی تصاویر را غیرممکن کنند.

## فونت

فونت Vazirmatn به‌صورت local در پوشه‌ی `fonts` قرار گرفته و با مجوز متن‌باز OFL استفاده شده است.
