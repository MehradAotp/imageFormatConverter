# مبدل تصویر پرو

### تبدیل حرفه‌ای تصاویر وب، سریع و کاملاً محلی

**Image Converter Pro** یک افزونه‌ی Chrome برای تبدیل، تغییر اندازه و خروجی گرفتن از تصاویر صفحات وب است. این پروژه توسط **MrAOTP** طراحی و توسعه داده شده است.

> رابط کاربری افزونه با فونت **Vazirmatn** نسخه‌ی `v33.003` به‌صورت local ارائه می‌شود و هیچ وابستگی‌ای به Google Fonts یا CDN ندارد.

## امکانات

- تبدیل با راست‌کلیک به PNG، JPG، WebP، AVIF، BMP و TIFF
- encoder داخلی برای BMP و TIFF
- گزارش خطا به‌جای fallback بی‌صدا به PNG
- داشبورد فارسی و راست‌به‌چپ برای کشف، فیلتر، مرتب‌سازی و انتخاب تصاویر
- پیش‌نمایش بزرگ با مقایسه‌ی قبل و بعد
- rotate، flip و crop سریع در ویرایشگر
- تبدیل گروهی و دریافت خروجی در ZIP واقعی
- شناسایی تصویرهای معمولی، lazy، `<picture>`, `<source>` و `background-image`
- تغییر اندازه با حفظ نسبت تصویر
- تنظیم کیفیت WebP، JPG و AVIF
- تنظیم حجم هدف برای فرمت‌های فشرده
- انتخاب فرمت پیشنهادی بر اساس نوع تصویر و ابعاد
- پردازش محلی و بدون ارسال تصویر به سرویس شخص ثالث

## نصب

1. به `chrome://extensions` بروید.
2. **Developer mode** را فعال کنید.
3. روی **Load unpacked** کلیک کنید.
4. پوشه‌ی پروژه را انتخاب کنید.
5. اگر افزونه قبلاً نصب است، بعد از تغییر فایل‌ها روی **Reload** بزنید و صفحه‌ی وب را refresh کنید.

## فونت Vazirmatn

فایل‌های زیر از بسته‌ی رسمی Vazirmatn در پروژه قرار گرفته‌اند:

```text
fonts/Vazirmatn-Regular.woff2
fonts/Vazirmatn-Bold.woff2
fonts/fonts.css
fonts/OFL.txt
```

صفحه‌های داخلی افزونه (`popup.html` و `options.html`) مستقیماً `fonts/fonts.css` را load می‌کنند. داشبوردی که داخل صفحه‌ی وب نمایش داده می‌شود نیز همین stylesheet را از مسیر extension URL به‌صورت local اضافه می‌کند.

استفاده از فونت مطابق **SIL Open Font License 1.1** است.

## محدودیت‌ها

- AVIF فقط در مرورگرهایی تولید می‌شود که encoder مربوط به Canvas را پشتیبانی کنند.
- BMP و TIFF توسط encoder ساده‌ی داخلی ساخته می‌شوند و فشرده‌سازی پیشرفته ندارند.
- محدودیت CORS، احراز هویت، منابع محافظت‌شده و صفحات `chrome://` ممکن است مانع دسترسی به تصویر شوند.
- تصاویر CSS با URL نسبی یا منابعی که دسترسی مستقیم ندارند ممکن است قابل پردازش نباشند.
- برای تصاویر بسیار بزرگ، مصرف حافظه و زمان پردازش بیشتر خواهد بود.
