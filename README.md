# Image Converter Pro

A privacy-first Chrome Manifest V3 toolbox designed and built by **MrAOTP**.

## Features

- Right-click conversion to PNG, JPG, WebP, AVIF, BMP, or TIFF.
- Real client-side BMP and TIFF encoders; the extension no longer silently downloads PNG when those formats are requested.
- AVIF uses native browser encoding and clearly reports when the current browser does not support it.
- Premium page dashboard with image discovery, preview cards, search/filter, select-all, and batch export.
- High-quality resizing with aspect ratio preservation.
- Configurable WebP, JPG, and AVIF quality.
- Custom JPG background color for transparent images.
- Original filename or timestamp naming.
- All processing happens locally in the browser.

## Install locally

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Choose **Load unpacked**.
4. Select this project directory.

## Use

Right-click an image and select **Image Converter Pro → Convert to…**. To process a page, right-click anywhere and choose **Open page image dashboard**, or open the extension popup and click **Scan this page**.

Open **Extension options** for quality, resize, naming, and JPG background preferences.

## Browser limitations

AVIF encoding depends on browser canvas support. BMP and TIFF are generated by the extension's own encoders. Cross-origin restrictions, authentication, protected resources, and Chrome internal pages can still prevent access to some images.
