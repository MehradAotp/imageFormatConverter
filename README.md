# مبدل تصویر پرو

### تبدیل حرفه‌ای تصاویر وب، سریع و کاملاً محلی

**Image Converter Pro** یک افزونه‌ی Chrome برای تبدیل، تغییر اندازه و خروجی گرفتن از تصاویر صفحات وب است. این پروژه توسط **MrAOTP** طراحی و توسعه داده شده و هدفش ارائه‌ی یک ابزار سریع، شفاف و کاربردی بدون وابستگی به سرویس‌های آنلاین است.

## چرا این افزونه؟

گاهی فقط می‌خواهید یک تصویر را با فرمت مناسب ذخیره کنید، حجم آن را کم کنید یا چند تصویر صفحه را هم‌زمان پردازش کنید؛ بدون آپلود تصویر در وب‌سایت‌های ناشناس و بدون بازکردن ابزارهای پیچیده.

این افزونه این کار را مستقیماً در مرورگر انجام می‌دهد و از منوی راست‌کلیک یا داشبورد تصویری در اختیار شما قرار می‌گیرد.

## امکانات اصلی

### تبدیل تکی با راست‌کلیک

روی هر تصویر قابل‌دسترسی راست‌کلیک کنید و از منوی **مبدل تصویر پرو · MrAOTP** فرمت خروجی را انتخاب کنید:

- PNG
- JPG
- WebP
- AVIF
- BMP
- TIFF

برای BMP و TIFF از encoder داخلی افزونه استفاده می‌شود؛ بنابراین این فرمت‌ها به‌صورت ناخواسته به PNG تبدیل نمی‌شوند. AVIF به پشتیبانی encoder مرورگر وابسته است و در صورت پشتیبانی‌نشدن، خطای واضح نمایش داده می‌شود.

### داشبورد تصاویر صفحه

با انتخاب گزینه‌ی **باز کردن داشبورد تصاویر صفحه** یا کلیک روی **اسکن تصاویر این صفحه** می‌توانید:

- تصاویر صفحه را یک‌جا پیدا کنید؛
- پیش‌نمایش هر تصویر را ببینید؛
- با جست‌وجو بر اساس آدرس تصویر یا متن جایگزین، موارد دلخواه را فیلتر کنید؛
- تصاویر را بر اساس عرض، ارتفاع یا مساحت مرتب کنید؛
- یک یا چند تصویر را انتخاب کنید؛
- با دابل‌کلیک یا کلیک راست روی کارت، تصویر را در preview بزرگ ببینید؛
- تصاویر انتخاب‌شده را به‌صورت گروهی تبدیل و دانلود کنید.

### تنظیمات حرفه‌ای

از صفحه‌ی تنظیمات می‌توانید این موارد را کنترل کنید:

- کیفیت WebP، JPG و AVIF؛
- حداکثر عرض و ارتفاع خروجی با حفظ نسبت تصویر؛
- رنگ پس‌زمینه برای تبدیل تصاویر شفاف به JPG؛
- استفاده از نام فایل اصلی یا نام‌گذاری بر اساس زمان تبدیل.

## نصب در حالت توسعه‌دهنده

> این روش برای استفاده‌ی شخصی و توسعه است و به انتشار در Chrome Web Store نیاز ندارد.

1. این مخزن را دریافت کنید:

   ```bash
   git clone git@github.com:MehradAotp/imageFormatConverter.git
   cd imageFormatConverter
   ```

2. در Chrome به آدرس زیر بروید:

   ```text
   chrome://extensions
   ```

3. گزینه‌ی **Developer mode** را فعال کنید.
4. روی **Load unpacked** کلیک کنید.
5. پوشه‌ی پروژه را انتخاب کنید.

پس از هر تغییر، از صفحه‌ی افزونه‌ها روی دکمه‌ی **Reload** کلیک کنید. اگر content script تغییر کرده باشد، صفحه‌ی وب را نیز refresh کنید.

## روش استفاده

### تبدیل سریع یک تصویر

1. روی تصویر کلیک راست کنید.
2. منوی **مبدل تصویر پرو · MrAOTP** را باز کنید.
3. فرمت خروجی را انتخاب کنید.
4. مسیر ذخیره را در پنجره‌ی دانلود Chrome مشخص کنید.

### تبدیل چند تصویر

1. افزونه را از نوار ابزار Chrome باز کنید.
2. روی **اسکن تصاویر این صفحه** کلیک کنید.
3. تصاویر موردنظر را انتخاب یا از **انتخاب همه** استفاده کنید.
4. فرمت خروجی را انتخاب کنید.
5. روی **خروجی گرفتن** کلیک کنید.

### مشاهده‌ی تصویر در اندازه‌ی بزرگ

در داشبورد، روی تصویر دابل‌کلیک کنید یا روی آن کلیک راست کنید. برای بستن preview، روی ×، پس‌زمینه یا کلید `Escape` استفاده کنید.

## حریم خصوصی

پردازش تصویر در همان مرورگری انجام می‌شود که افزونه روی آن نصب شده است. افزونه برای تبدیل، تصویر را به سرویس شخص ثالث ارسال نمی‌کند.

بااین‌حال، برای دسترسی به تصاویر صفحات مختلف، Chrome باید اجازه‌ی دسترسی به منابع وب را در اختیار افزونه قرار دهد. این موضوع با پردازش ابری یا ارسال تصویر به سرور تفاوت دارد.

## محدودیت‌های واقعی

این افزونه نمی‌تواند تضمین کند که هر تصویر در هر سایتی قابل تبدیل است. موارد زیر ممکن است باعث شکست عملیات شوند:

- تصویر به احراز هویت، کوکی خاص یا دسترسی محدود نیاز داشته باشد؛
- سایت یا منبع تصویر درخواست cross-origin را مسدود کند؛
- صفحه از نوع داخلی Chrome مانند `chrome://` باشد؛
- مرورگر فعلی encoder داخلی AVIF را ارائه نکند؛
- تصویر بیش از ظرفیت حافظه یا محدودیت Canvas مرورگر بزرگ باشد؛
- منبع تصویر در لحظه‌ی پردازش دیگر در دسترس نباشد.

BMP و TIFF در افزونه encoder اختصاصی دارند، اما این خروجی‌ها ساده و بدون فشرده‌سازی پیشرفته هستند. برای فایل‌های بسیار بزرگ، زمان پردازش و مصرف حافظه می‌تواند قابل‌توجه باشد.

## ساختار پروژه

```text
.
├── background.js       # منوی راست‌کلیک، دانلود و اعلان‌ها
├── content.js          # اسکن صفحه، تبدیل تصویر و داشبورد
├── popup.html/js/css   # پنجره‌ی اصلی افزونه
├── options.html/js/css # تنظیمات کیفیت و خروجی
├── manifest.json       # پیکربندی Manifest V3
├── fonts/              # فونت محلی Vazirmatn و مجوز OFL
└── icons/              # آیکن‌های افزونه
```

## مجوزهای استفاده‌شده

- `contextMenus`: ساخت منوی راست‌کلیک روی تصاویر؛
- `downloads`: ذخیره‌ی فایل‌های تبدیل‌شده؛
- `storage`: نگهداری تنظیمات کاربر؛
- `notifications`: نمایش خطاهای تبدیل؛
- `host_permissions`: دسترسی به تصاویر صفحات وب برای اسکن و پردازش.

این مجوزها برای قابلیت‌های فعلی افزونه استفاده می‌شوند و پردازش تصویر در سمت کاربر انجام می‌شود.

## وضعیت پروژه

نسخه‌ی فعلی برای استفاده‌ی محلی و توسعه آماده است. تمرکز فعلی روی تبدیل تکی، پردازش گروهی و تجربه‌ی کاربری فارسی است.

## ایده‌های منطقی برای توسعه‌ی بعدی

موارد زیر قابلیت‌های قابل‌اجرا و ارزشمند برای نسخه‌های بعدی هستند:

- پشتیبانی از تصاویر `background-image` و منابع lazy-loaded؛
- برش، چرخش و flip پیش از خروجی؛
- مقایسه‌ی قبل و بعد با نمایش حجم فایل؛
- فشرده‌سازی بر اساس حجم هدف، مانند «کمتر از ۲۰۰ کیلوبایت»؛
- کشف و پردازش فایل‌های محلی با drag & drop؛
- نوار پیشرفت دقیق‌تر برای صف‌های بزرگ؛
- ساخت فایل ZIP برای خروجی‌های گروهی؛
- بررسی خودکار فرمت مناسب بر اساس شفافیت، ابعاد و حجم تصویر.

این موارد در نسخه‌ی فعلی ادعا نمی‌شوند و به‌عنوان مسیر توسعه‌ی آینده در نظر گرفته شده‌اند.
