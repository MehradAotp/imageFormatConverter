## درباره‌ی پروژه

**مبدل تصویر پرو** یک افزونه‌ی Chrome مبتنی بر Manifest V3 است که امکان تبدیل تصاویر قابل‌دسترسی در صفحات وب را فراهم می‌کند. تمرکز پروژه روی یک تجربه‌ی سریع، فارسی، راست‌به‌چپ و local-first است؛ یعنی پردازش تصویر در سمت کاربر انجام می‌شود و تصویر برای تبدیل به سرور اختصاصی پروژه ارسال نمی‌شود.

این پروژه برای استفاده‌ی روزمره، تبدیل سریع از منوی راست‌کلیک و مدیریت چند تصویر از طریق داشبورد طراحی شده است.

## امکانات فعلی

### تبدیل و خروجی

- تبدیل از منوی راست‌کلیک به `PNG`، `JPG`، `WebP`، `AVIF`، `BMP` و `TIFF`
- تبدیل تکی و تبدیل گروهی
- ساخت فایل `ZIP` برای خروجی‌های گروهی
- حفظ شفافیت در فرمت‌های مناسب
- قرار دادن پس‌زمینه‌ی قابل‌تنظیم برای خروجی JPG
- تنظیم کیفیت WebP، JPG و AVIF
- تعیین حجم هدف برای JPG، WebP و AVIF؛ ابزار تا حد امکان کیفیت را برای رسیدن به حجم هدف کاهش می‌دهد
- تغییر اندازه‌ی اختیاری با حفظ نسبت تصویر
- نام‌گذاری بر اساس نام اصلی یا زمان تبدیل

### کشف تصاویر

داشبورد می‌تواند منابع زیر را در صفحه شناسایی کند:

- تصاویر معمولی `<img>`
- برخی منابع lazy-loaded مانند `data-src`، `data-lazy-src` و `data-original`
- منابع `<picture>` و `<source srcset>`
- برخی تصاویر استفاده‌شده در `background-image`
- منابع `http`، `https`، `data` و `blob` در صورت قابل‌دسترسی بودن

### داشبورد و ویرایشگر

- رابط فارسی و راست‌به‌چپ با طراحی تاریک
- جست‌وجو بر اساس آدرس یا متن جایگزین تصویر
- مرتب‌سازی بر اساس عرض، ارتفاع و مساحت
- انتخاب تکی یا انتخاب همه‌ی تصاویر
- پیش‌نمایش مناسب تصاویر با حفظ نسبت واقعی
- اسکرول داخلی شبکه‌ی تصاویر برای صفحات دارای تعداد زیاد تصویر
- باز کردن ویرایشگر با دابل‌کلیک یا کلیک راست روی کارت تصویر
- پیش‌نمایش زنده‌ی یکپارچه
- چرخش ۹۰ درجه
- flip افقی و عمودی
- crop سریع ۱۰٪
- نمایش وضعیت پردازش و حجم خروجی

### تجربه و حریم خصوصی

- پردازش تصویر در سمت کاربر انجام می‌شود.
- برای فونت Vazirmatn از CDN یا Google Fonts استفاده نمی‌شود.
- گزارش خطا برای تصاویر غیرقابل‌دسترسی به‌جای fallback بی‌صدا نمایش داده می‌شود.
- داده‌ی تصویر در history ذخیره نمی‌شود؛ فقط اطلاعات خلاصه‌ی تبدیل نگهداری می‌شود.

## نصب در حالت توسعه

> این پروژه در حال حاضر برای نصب محلی از طریق **Load unpacked** آماده است.

### روش گرافیکی

1. این مخزن را دریافت یا clone کنید.
2. در Chrome به `chrome://extensions` بروید.
3. گزینه‌ی **Developer mode** را فعال کنید.
4. روی **Load unpacked** کلیک کنید.
5. پوشه‌ی اصلی پروژه، یعنی پوشه‌ای که `manifest.json` داخل آن است، انتخاب کنید.
6. پس از هر تغییر، روی **Reload** بزنید و صفحه‌ی وب را refresh کنید.

### دریافت با Git

```bash
git clone git@github.com:MehradAotp/imageFormatConverter.git
cd imageFormatConverter
```

سپس پوشه را از طریق `chrome://extensions` به‌صورت unpacked بارگذاری کنید.

## روش استفاده

### تبدیل سریع یک تصویر

1. روی یک تصویر در صفحه کلیک راست کنید.
2. منوی **مبدل تصویر پرو · MrAOTP** را باز کنید.
3. فرمت خروجی را انتخاب کنید.
4. محل ذخیره را در پنجره‌ی دانلود Chrome مشخص کنید.

### استفاده از داشبورد

1. روی آیکن افزونه کلیک کنید و **اسکن تصاویر این صفحه** را بزنید؛ یا از منوی راست‌کلیک، داشبورد را باز کنید.
2. تصاویر موردنظر را انتخاب کنید.
3. فرمت خروجی را انتخاب کنید یا **پیشنهاد هوشمند** را به‌کار ببرید.
4. روی **خروجی گرفتن** کلیک کنید تا فایل ZIP ساخته و دانلود شود.
5. برای ویرایش یک تصویر، روی thumbnail دابل‌کلیک یا کلیک راست کنید.

## تنظیمات

از بخش **تنظیمات پیشرفته** می‌توانید این موارد را تغییر دهید:

- کیفیت WebP، JPG و AVIF
- حداکثر عرض و ارتفاع خروجی
- حجم هدف بر حسب کیلوبایت
- رنگ پس‌زمینه‌ی JPG
- روش نام‌گذاری فایل

## فرمت‌ها و encoderها

| فرمت | روش تولید | نکته |
|---|---|---|
| PNG | Canvas مرورگر | مناسب برای شفافیت و تصاویر بدون افت |
| JPG | Canvas مرورگر | شفافیت به رنگ پس‌زمینه تبدیل می‌شود |
| WebP | Canvas مرورگر | کیفیت و حجم قابل تنظیم |
| AVIF | Canvas مرورگر | به پشتیبانی encoder مرورگر وابسته است |
| BMP | encoder داخلی ساده | خروجی ۲۴ بیتی بدون فشرده‌سازی پیشرفته |
| TIFF | encoder داخلی ساده | TIFF پایه با داده‌ی RGBA و بدون فشرده‌سازی پیشرفته |

اگر مرورگر encoder یک فرمت را پشتیبانی نکند، افزونه باید خطا اعلام کند و نباید آن را بی‌صدا به PNG تبدیل کند.

## محدودیت‌های واقعی

این افزونه نمی‌تواند محدودیت‌های امنیتی مرورگر یا سیاست‌های سرور را حذف کند. تبدیل ممکن است برای موارد زیر ناموفق باشد:

- تصاویر نیازمند احراز هویت یا کوکی خاص
- تصاویر دارای توکن منقضی‌شده یا لینک موقت
- سرورهایی که دسترسی مستقیم، hotlink یا درخواست افزونه را مسدود می‌کنند
- منابعی که CORS یا سیاست‌های امنیتی سرور مانع دریافت آن‌ها می‌شود
- تصاویر موجود در صفحات داخلی Chrome مانند `chrome://`
- تصاویر بسیار بزرگ که حافظه و زمان زیادی مصرف می‌کنند
- `background-image`های شامل gradient، URL نسبی نامعتبر یا چند منبع پیچیده
- تصاویر `blob:` که فقط در context همان صفحه معتبر هستند

در صورت شکست دریافت تصویر، راه عملی جایگزین این است که تصویر را با مرورگر ذخیره کنید و در نسخه‌ی دارای drag & drop وارد کنید؛ drag & drop فایل محلی هنوز جزو قابلیت‌های کامل این نسخه نیست.

## مجوزهای افزونه

| مجوز | کاربرد |
|---|---|
| `contextMenus` | افزودن گزینه‌های تبدیل به منوی راست‌کلیک |
| `downloads` | ذخیره‌ی خروجی و فایل ZIP |
| `storage` | ذخیره‌ی تنظیمات و history خلاصه‌ی تبدیل‌ها |
| `notifications` | نمایش خطاها و اعلان‌های تبدیل |
| `activeTab` | تعامل با تب فعال |
| `scripting` | پشتیبانی از اجرای اسکریپت‌های لازم در تب |
| `<all_urls>` | دریافت منابع تصویر از سایت‌های مختلف در service worker |

## ساختار پروژه

```text
.
├── background.js       # service worker، منوی راست‌کلیک و دانلود
├── content.js          # کشف تصاویر، داشبورد و pipeline تبدیل
├── manifest.json       # تنظیمات Manifest V3
├── popup.html/js/css   # رابط popup افزونه
├── options.html/js/css # صفحه‌ی تنظیمات
├── fonts/              # فونت local و مجوز آن
├── icons/              # آیکن‌های افزونه
├── .gitignore          # فایل‌های محلی و metadata محیط توسعه
└── README.md           # مستندات پروژه
```

## فونت Vazirmatn

فونت **Vazirmatn** به‌صورت local در پروژه قرار دارد:

```text
fonts/Vazirmatn-Regular.woff2
fonts/Vazirmatn-Bold.woff2
fonts/fonts.css
fonts/OFL.txt
```

صفحه‌های popup و تنظیمات مستقیماً stylesheet محلی را بارگذاری می‌کنند. داشبورد نیز stylesheet فونت را با `chrome.runtime.getURL()` از خود افزونه دریافت می‌کند.

فونت تحت **SIL Open Font License 1.1** استفاده شده است.

## وضعیت پروژه

این پروژه یک افزونه‌ی محلی و قابل نصب برای Chrome است. قابلیت‌ها و محدودیت‌های مستندشده در بالا بر اساس پیاده‌سازی فعلی نوشته شده‌اند؛ مواردی که هنوز کامل نیستند به‌عنوان قابلیت قطعی معرفی نشده‌اند.

## مشارکت

برای پیشنهاد قابلیت، گزارش خطا یا بهبود رابط کاربری:

1. یک Issue با توضیح دقیق، URL منبع در صورت امکان و مراحل بازتولید ایجاد کنید.
2. برای تغییرات مشخص، Pull Request ارسال کنید.
3. از قرار دادن تصویرهای خصوصی، tokenها یا اطلاعات ورود در Issue و logها خودداری کنید.

## مجوز

مجوز اختصاصی برای خود کد پروژه در این مخزن مشخص نشده است. پیش از استفاده‌ی مجدد، انتشار یا توزیع کد، با سازنده هماهنگ کنید.

فونت Vazirmatn مستقل از کد پروژه و تحت مجوز **SIL OFL 1.1** ارائه می‌شود؛ متن کامل آن در `fonts/OFL.txt` قرار دارد.
